# FormAI Design System

## Design Context

### Users
**Dual audience** — developers embedding FormAI into their own products, and non-technical business users building forms visually. Both groups use it in a focused, task-driven context. Developers want power and flexibility; non-technical users want confidence and ease. The interface must make both feel at home without compromising for either.

### Brand Personality
**Powerful / Friendly / Modern**

FormAI is the smart collaborator — it does the heavy lifting while making you feel like a genius. The tone is warm but not cute, confident but not intimidating. Think: a brilliant colleague who makes complex things feel obvious.

Emotional goal: **"This is magic."** Users should feel wonder and delight — like the tool is thinking with them, not just executing commands.

### Aesthetic Direction
- **Theme**: Dark glassmorphic base (deliberate brand direction — keep and strengthen)
- **Palette**: Deep dark backgrounds with indigo/purple accents. Strategic color moments — not gradient overload. Tinted neutrals leaning toward indigo.
- **Reference**: hashbrown.dev — "serious but approachable engineering." Clean layout with breathing room, playful personality embedded in a professional shell, SVG illustrations that add warmth without being childish, strategic accent colors rather than wall-to-wall gradients.
- **Anti-references**: No generic enterprise SaaS (Salesforce, Google Forms-style). No sterile, soulless interfaces. No dark-mode-with-glowing-cyan AI clichés.
- **Typography**: Distinctive display font for headings (not Inter). Clean, readable body font. Bold hierarchy. No monospace-as-personality shorthand.
- **Motion**: Purposeful and smooth. Entrances with staggered reveals. Interactions that confirm and delight. Exponential easing. Never bouncy or elastic.

### Design Principles
1. **Magic is effortless** — The AI features should appear as natural extensions of the user's intent, not as separate "AI modes." Every AI interaction should feel inevitable in hindsight.
2. **Power without intimidation** — Expose complexity progressively. Start simple, reveal depth through interaction. Developers can go deep; non-devs never have to.
3. **Dark with intention** — The glassmorphic dark theme is brand identity, not a trend. Use blur, depth, and layering purposefully to create spatial hierarchy, not just visual texture.
4. **Breathe and accent** — Generous spacing creates calm. Reserve color for meaning — highlights, states, calls-to-action. Strategic pops over ambient gradients.
5. **Personality lives in details** — Copywriting, micro-animations, empty states, and transition moments should carry the "friendly" half of the brand. The unexpected small thing is what people remember.

### Technical Constraints
- Vue 3 + TypeScript + Tailwind CSS 4
- Lucide icons (vue-next)
- RTL support required (Arabic + English via vue-i18n)
- Light theme in builder canvas, dark theme on marketing/landing pages
- WCAG AA as target — semantic HTML, keyboard navigation, reduced-motion support, sufficient contrast ratios
